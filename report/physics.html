The physics

1D special relativity under a constant force

The ground truth for every sample in this project comes from one governing law: dp/dt = F with p = γmv — not the classical F = ma. This page presents the exact closed-form solution, the reference implementation that computes it, and an interactive explorer for how β, γ, momentum and energy behave as a particle approaches the speed of light. Full definitions and notation are collected in the Research report's terminology section.

Theoretical model

Governing equation

For a particle of rest mass m under constant force F, momentum grows linearly in time:

p(t) = p₀ + F·t,   q = p / (m·c),   γ = √(1 + q²),   v = c·q/γ

Total and kinetic energy follow from the same momentum:

E = √(m²c⁴ + p²c²)    K = p²c² / (E + mc²)

Position is evaluated in a cancellation-free form that stays accurate at high β and small impulse:

x(t) = x₀ + c·t·(q + q₀) / (γ + γ₀)

Proper time accumulates from dτ = dt/γ, using a stable log1p rapidity-increment form to avoid cancellation when the impulse is tiny relative to the initial momentum.

Scientific scope

Included: flat Minkowski spacetime, one spatial dimension, constant rest mass, an externally applied constant 1D force, SI units.

Excluded: gravity, curved spacetime, electromagnetic-field models, radiation reaction, variable mass, quantum effects, faster-than-light / spacelike trajectories.

Numerical precision: IEEE-754 float64. States are rejected rather than clipped when they cannot be represented as strictly subluminal — the engine never silently clips to the light cone.

Reference implementation

The relativistic-simulator package

Every dataset in this report is generated by a special-relativity simulator designed, implemented, tested, and published as an independent open-source package. It is the ground-truth physics engine for the entire pipeline: it computes exact values from the closed-form equations above — it does not fit or discover physics, and it contains no learned component.

API

Quick start

Simulate a single trajectory 
from relativistic_simulator import C, simulate

result = simulate(
    mass=1000.0, force=1e6, initial_velocity=0.9 * C,
    duration=100.0, dt=0.01,
)

print(result.beta, result.gamma, result.momentum)
print(result.kinetic_energy, result.total_energy, result.proper_time)
print(result.validate().summary())

simulate() returns a Trajectory exposing time, position, velocity, beta, gamma, momentum, kinetic_energy, total_energy, and proper_time, plus to_numpy(), to_dict(), to_dataframe(), and final_state().

Generate a vectorized dataset 
from relativistic_simulator import generate_dataset

dataset = generate_dataset(
    n_samples=100_000,
    mass_range=(100.0, 10_000.0),
    force_range=(1e4, 1e7),
    beta_range=(0.0, 0.8),
    time_range=(0.0, 100.0),
    random_seed=42,
)

dataset.to_csv("train.csv")
print(dataset.input_columns)   # ('mass','force','initial_velocity','initial_beta','time')
print(dataset.output_columns)  # ('position','velocity','beta','gamma','momentum',
                                #  'kinetic_energy','total_energy','proper_time')

Generation is fully vectorized with NumPy and uses numpy.random.default_rng, so seeded datasets are exactly reproducible. This project's data_gen.ipynb instead drives simulate() directly in a per-row loop so it can control an explicit β mixture — see the Datasets page for exactly how.

Independent quantitative validation

validate_trajectory and validate_dataset check p = γmv, E = γmc², the energy-momentum invariant, central finite differences for dp/dt and dx/dt, proper time, initial conditions, the velocity bound, and τ ≤ t — using independent routes rather than repeating the generating expression.

report = result.validate()
print(report.max_energy_momentum_error)
print(report.max_force_error)
print(report.passed)

Running this validation on the 1,000,000-row dataset used throughout this project returned passed=True with a max energy-momentum invariant error of 3.2×10⁻¹⁵ and zero velocity-bound violations — see Datasets → Validation for the full report.

Numerical method

Why the engine avoids naive formulas

🎯

Cancellation-free position

Position is evaluated as x₀ + ct(q+q₀)/(γ+γ₀) — algebraically equal to x₀+(K−K₀)/F, but stable at high β and small impulse where the latter subtracts two nearly-equal large energies.

⏱️

Stable proper time

Proper time uses a log1p rapidity-increment form instead of asinh(q) − asinh(q₀), avoiding cancellation when the impulse is tiny relative to the initial momentum.

🚫

No silent clipping

Inputs with |v| ≥ c, |β| ≥ 1, non-positive mass, or non-finite values raise typed exceptions. States are never silently clipped to the light cone.

The package test suite (uv run pytest) covers high-β trajectories through 0.99999c, invalid physical states, exact/RK4 agreement, vectorization, reproducibility, dataset validation, and optional plotting. uv build produces wheel and source distributions.
