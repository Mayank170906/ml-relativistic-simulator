Relativistic Physics × Machine Learning

Learning relativistic dynamics from synthetic simulation

A custom special-relativity simulator generates exact ground truth for eight physical quantities under constant 1D force. This report documents every dataset, model family, and evaluation the project ran — including where the models succeeded and where they failed.

The physics engine was independently designed and published to PyPI

Every ground-truth value in this project comes from relativistic-simulator, a special-relativity physics engine designed and released as an independent open-source package — not a wrapper around an existing library. Every model is implemented directly with NumPy, PyTorch, and scikit-learn: no pretrained components, no AutoML.
