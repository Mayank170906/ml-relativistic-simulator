This project was developed and run entirely within Jupyter notebooks — there is no hidden pipeline or framework operating behind the scenes. Each notebook below was exported to HTML exactly as it ran, with code, output, and plots intact, and is linked here with a description of its role in the pipeline. Selecting a notebook opens its full export in a new tab.

Attribution

The physics engine, datasets, and every model here were built from the ground up

The ground-truth physics simulator underlying every dataset in this project — relativistic-simulator — was designed, implemented, tested, and published by the author as an independent package. No notebook in this project imports a pre-built relativity library, a pretrained model, or a high-level AutoML framework: each one is written directly against NumPy, PyTorch, and scikit-learn.
