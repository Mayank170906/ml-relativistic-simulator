Every number presented in this report is drawn directly from the project's own result files, notebooks, and trained models, without alteration. Where a finding is uncertain or confounded by an experimental limitation, it is explicitly labeled as such (see Research → Conclusions).

5. Contributions and collaboration

This project is under active development, and outside input is welcome. If you would like to help extend the research, you're encouraged to:

  • Open an issue or pull request on the physics engine's GitHub repository — bug reports, additional validation tests, and API suggestions are all useful.
  • Propose or run one of the open experiments listed under Future Work — for example, re-running the polynomial-feature network with a matched batch size, or building a genuinely held-out extrapolation set for the current training distribution.
  • Reach out directly with questions, corrections, or ideas for follow-up experiments.

Any contribution submitted for inclusion in this project is accepted under the same MIT License that covers the rest of the work.
